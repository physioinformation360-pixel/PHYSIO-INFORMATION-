## 📌 Project Overview

**PHYSIO INFORMATION** is a professional physiotherapy clinic management web application designed to help physiotherapists manage:

- Client details
- Treatment sessions & progression
- Payment history & balance
- Bill PDF generation with logo & branding

This system is **admin-only**, mobile-friendly, and built for real-world clinical use.

---

## 🚀 Features

- 🔐 **Admin-only login**
- 👤 **Client Management**
  - Add / edit clients
  - Track active & completed cases
- 🏃 **Session Tracking**
  - Total sessions
  - Completed & remaining sessions
- 💰 **Payment Management**
  - Payments received
  - Pending balance
- 🧾 **Bill PDF Generation
